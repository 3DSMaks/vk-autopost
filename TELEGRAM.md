# Автопостинг в Telegram

RSS и Gemini берутся из post.py. VK API не вызывается. Пост содержит от одного до трёх изображений и текст со ссылкой на источник. Для Telegram ведётся отдельный seen_telegram.json; новости, ранее вышедшие только в ВК, могут выйти и здесь.

## Подключение

1. Откройте https://t.me/BotFather, отправьте /newbot, задайте имя и свободный username с окончанием bot.
2. Добавьте бота администратором своего Telegram-канала с правом публикации сообщений.
3. В GitHub Settings → Secrets and variables → Actions → Secrets добавьте TELEGRAM_BOT_TOKEN (токен BotFather) и TELEGRAM_CHAT_ID (@username публичного канала либо числовой ID приватного канала). Существующий GEMINI_API_KEY используется повторно.
4. Actions → Новости в Telegram → Run workflow → check проверяет бота и права без публикации. publish отправляет одну настоящую новость.
5. После успешной проверки и первой публикации добавьте в Variables переменную TELEGRAM_ENABLED со значением true. Расписание: раз в час на 10-й минуте UTC; GitHub может задерживать запуск. Для остановки установите false.

До включения TELEGRAM_ENABLED автоматические публикации отключены. Push запускает только тесты. При отсутствии изображений текст без фото не публикуется.

Не отправляйте токен в переписку и не сохраняйте его в коде. При сетевой ошибке отправки сначала проверьте канал: запрос мог быть выполнен Telegram, даже если ответ не дошёл. Не запускайте повторно вслепую. Если публикация прошла, но сохранение истории в GitHub завершилось ошибкой, восстановите историю до следующего запуска, чтобы избежать повтора.

Тесты: python -m unittest -v test_telegram.py
